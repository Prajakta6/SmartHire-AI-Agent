Improved Answer:  
In Python there are three built‑in collection types that are often compared:

* **List** – An ordered collection that can contain duplicate items.  
  - Mutable: you can add, remove, or change elements (`append`, `pop`, assignment, etc.).  
  - Supports indexing and slicing, so you can access `my_list[2]` or `my_list[1:4]`.  
  - Good for sequences where order matters and the data may change.

* **Tuple** – Also an ordered collection, but it is **immutable**.  
  - Once created you cannot change, add, or delete its elements (no `append` or item assignment).  
  - Because it is immutable, a tuple can be used as a dictionary key or stored in a set.  
  - Like lists, it allows duplicate values and supports indexing and slicing.

* **Set** – An unordered collection of **unique** items.  
  - Mutable: you can add or remove elements (`add`, `remove`, `discard`).  
  - No indexing or slicing because there is no defined order.  
  - Automatically removes duplicates, making it ideal for membership testing and for performing mathematical set operations (`union`, `intersection`, `difference`, `symmetric_difference`).  
  - Look‑ups are fast (average O(1) time).

Choosing the right type depends on whether you need order, mutability, or uniqueness.
