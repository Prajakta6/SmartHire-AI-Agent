**Improved Answer:**  
> In Python there are three built‑in collection types that are often compared: **list**, **tuple**, and **set**.  
> 
> 1. **List (`[]`)** – *mutable, ordered, allows duplicates*  
>    - You can add, remove, or change items with methods like `append`, `pop`, or assignment (`mylist[0] = 5`).  
>    - Elements keep the order you insert them, so you can access any item by its index (`mylist[2]`).  
>    - Because duplicates are allowed, `[1, 2, 2]` is a valid list.  
>    - Membership test (`x in mylist`) scans the list, taking O(n) time.  
> 
> 2. **Tuple (`()`)** – *immutable, ordered, allows duplicates*  
>    - Once created, its contents cannot be changed; no `append` or item assignment.  
>    - Like lists, tuples keep the insertion order and support indexing and slicing (`mytuple[1]`).  
>    - Because they never change, tuples are hashable (if all elements are hashable) and can be used as dictionary keys or set elements.  
>    - Useful for fixed collections of related items (e.g., coordinates) or for returning multiple values from a function.  
> 
> 3. **Set (`{}` with at least one element, or `set()`)** – *mutable, unordered, no duplicates*  
>    - Stores each value only once; adding an existing element has no effect.  
>    - Does not preserve order and does not support indexing (`myset[0]` raises an error).  
>    - Membership testing (`x in myset`) is O(1) on average, making sets ideal for fast look‑ups and deduplication.  
>    - Provides set algebra operations: `union (|)`, `intersection (&)`, `difference (-)`, and `symmetric_difference (^)`.  
>    - Empty curly braces `{}` create an empty **dictionary**; to create an empty set you must use `set()`.
