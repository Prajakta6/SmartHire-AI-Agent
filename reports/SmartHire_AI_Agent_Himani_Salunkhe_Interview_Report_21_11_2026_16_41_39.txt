**Improved Answer:**  
In Python there are three common built‑in collection types:

| Collection | Mutability | Order | Duplicates | Indexing | Typical Use |
|------------|------------|-------|------------|----------|-------------|
| **list**   | Mutable    | Preserves insertion order | Allowed | Yes (`mylist[0]`) | Ordered sequences that you need to modify (e.g., building a dynamic array). |
| **tuple**  | Immutable  | Preserves insertion order | Allowed | Yes (`mytuple[0]`) | Fixed collections, records, or keys for dictionaries because they are hashable. |
| **set**    | Mutable (elements must be hashable) | No guaranteed order | Not allowed (duplicates are automatically removed) | No (cannot use numeric index) | Storing unique items, fast membership tests, and performing mathematical set operations (`union`, `intersection`, etc.). |

**Key differences**  
- **Mutability:** Lists and sets can be changed after creation; tuples cannot.  
- **Ordering:** Lists and tuples keep the order you insert items; sets are unordered, so iterating over a set may produce items in any order.  
- **Duplicates:** Lists and tuples keep every element you add, even if it appears multiple times. Sets automatically discard duplicates, keeping only one copy of each distinct element.  
- **Hashability:** Elements stored in a set must be hashable (e.g., numbers, strings, tuples of hashable items). Because tuples are immutable, they are hashable and can be used as set elements or dictionary keys, while lists cannot.
